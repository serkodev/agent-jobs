# Conference proposal review

Review exactly one proposal for suitability for a Python conference.

Write `summary` in one or two sentences. Use `comment` to explain the decision with
specific reference to audience value, technical substance, clarity, and fit. Set
`vote` to `accept` or `reject`.

Judge only the supplied record. Do not compare it with other proposals and do not
assume information that is not present. Empty `abstract` or `detailed_description`
values are permitted by the input schema, but should count against clarity and
completeness when making the decision.
